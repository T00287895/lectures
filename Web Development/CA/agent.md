## Accessibility Guidelines
- Optimise and compress graphics to minimise download time.  
- Supply appropriate `alt` text for every image, using empty `alt` text only for purely decorative images.  
- Use neutral background colours with sufficient text contrast; choose colour combinations accessible to users with red/green colour blindness.  
- Build pages with fluid, dynamic layouts rather than fixed widths.  
- Ensure the site is browser- and system-independent; test across multiple browsers and screen resolutions.

## Deliverables
1. Create a folder named `SurnameForename` on the desktop.  
2. Save all HTML, image, and CSS files inside this folder.  
3. Compress (zip) the folder.  
4. Upload the zip file to the appropriate Canvas assignment.  
5. Verify that the file uploads correctly and meets the deadline; the student is responsible for timely and accurate submission.

## Referencing and Academic Integrity
- Reference any code taken from external sources directly within the code and clearly mark any modifications; failure to do so may result in a fail or a plagiarism record.  
- Reference external text and images if they are not original; comments within the code are acceptable for this purpose.  
- Familiarise yourself with the university’s anti-plagiarism policy.  
- Use the university’s approved referencing style wherever appropriate and clearly cite all sources in code or reference sections.  
- Do not use work from other students (past or present) without acknowledgement.  
- Do not employ professional agencies or AI services to produce the work.
