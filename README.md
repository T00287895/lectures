# MTU Kerry - Computing Department

## Programme Structure

- **Duration**: 2 semesters per academic year (12 weeks each)
- **Credits**: Modules worth ECTS credits (1 ECTS = 20-25 hours work)
- **Study composition**: Contact hours + Directed study + Independent study

## Assessments & Exams

### Continuous Assessment (CA)
- Occurs throughout the semester
- Multiple assessment methods: interim exams, projects, practicals, assignments
- Typical: 1-2 CAs per 5-credit module
- Results provided within 10 days
- **Missing CA**: Must contact lecturer immediately; no certificate = zero mark

### Final Examinations
- At the end of each semester
- Must pass to progress; if failed, must retake next sitting
- Timetables available via MyApps

### Key Rules
- Minimum 1 week notice before assessment
- Late submission penalties apply
- **Plagiarism policy**: A5.2 Anti-Plagiarism Policy applies
- Use **Harvard-Anglia referencing style**
- Keep copies of all submitted work

## Student Protocols

### Attendance & Punctuality
- Attendance tracked via QR/Canvas or manually
- **Your responsibility** to register attendance
- Late arrival may result in denial of entry
- Inform department if missing class

### Behaviour Standards
- Professional attitude required at all times
- Phones OFF or silent during classes
- No disruptive behaviour; persistent issues = disciplinary action
- Raise hand before speaking in lectures
- No unauthorized computer/phone use in class

### Communication
- Must be formal and respectful with staff
- Do NOT contact lecturers about exams once final exams start
- Class questions addressed during lectures
- For personal issues, speak to class tutor

### Special Circumstances
- **Illness/Injury**: Submit medical cert to department secretary within 1 week
- **Personal circumstances**: Notify class tutor or HOD
- **Exam-related issues**: Contact examinations office within 3 days
